## Что это

Директор отвечает на комментарии в Instagram по кодовому слову. Человек пишет
под постом «гайд», Директор отвечает ему в комментах и присылает в директ
сообщение с кнопкой. Нажал кнопку, получил гайд. Можно отдавать разное тем,
кто подписан, и тем, кто нет.

Ставится на ваш сервер, работает через ваше приложение Meta. Данные, токены
и переписка остаются у вас.

## Возможности

- Автоответы: кодовые слова под постом, ответ в комментах и в директ
- Проверка подписки: подписчикам одно, остальным другое
- Несколько аккаунтов Instagram в одной установке
- Пользователи и роли: владелец, участники, доступ к отдельным аккаунтам
- Очередь, которая укладывается в лимиты Instagram (750 ответов в час
  на аккаунт), когда пост залетает

## Почему self-hosted

Каждая установка работает через своё приложение Meta. Для своих аккаунтов
хватает Standard Access: не нужны App Review, верификация бизнеса и юрлицо.

## Стек

FastAPI, Postgres, Next.js, Caddy. Всё в docker compose.

## Разработка

```sh
docker compose -f docker-compose.dev.yml up -d   # Postgres для разработки
cd api && cp .env.example .env && uv sync
uv run alembic upgrade head
uv run uvicorn app.main:app --reload             # http://localhost:8000
uv run pytest                                    # включая границы модулей

cd web && npm install && npm run dev             # http://localhost:3000
```
